# v0.10.0

## Highlights

KubeDeck becomes KuchDesk across the agents, Helm chart, APIs and macOS tools.
This release adds guarded Host/Infisical workflows, bounded Kubernetes actions,
verified image reuse and recovery tools, and durable Grafana dashboard delivery.
The agent chart is **0.13.0** with app version **0.10.0**. Building all Go modules
requires **Go 1.26+**; the Host module declares 1.25 and the cluster module 1.26.

The fresh-install profile now uses `kubedesk-local-tls`. The source update alone
does not migrate other existing installations' active certificates, keys,
issuers or TLS routes. This development cluster completed a separately approved
migration to that name: its three new Certificates are Ready, trusted HTTPS
health checks pass and the three old `local-dev-tls` pairs remain for rollback.

## Added

- Host Doctor CLI/MCP diagnostics, a typed repair prompt and schema, and separate
  `doctor-readonly` and guarded `doctor-repair` scopes.
- A deployment CLI and opt-in MCP workflow with plan/start/status/cancel,
  revision checks, DNS/registry/resource preflight, image build/push, digest
  staging in KIND, Helm apply and rollout verification.
- Infisical CLI/MCP commands, name-only reads, project-access diagnostics and
  bounded asynchronous operations. Universal Auth tokens renew in memory;
  credentials come from a project-local `.env` or explicitly selected macOS
  Keychain item, with no automatic backend fallback.
- Official browser Admin login through `./infisical-login` and Host
  `admin-login`, including hidden Copy-to-clipboard recovery and server-checked
  human authority. Hybrid enrollment reconciles project access under an
  explicit policy; the Kubernetes bridge stays read-only for Infisical.
- An opt-in authenticated Host HTTPS bridge for Infisical metadata and Doctor
  checks. Host administration stays in the scoped local CLI/MCP; bootstrap
  credentials are not placed in Pods or Helm values. Other projects need their
  own membership and bridge allowlist setup.
- Guarded Kubernetes Job status/run/delete, asynchronous scale/restart,
  WebSocket Pod port-forwarding and noninteractive Pod exec. Identity checks,
  bounded work and explicit feature gates apply; exec is disabled by default.
- Go site rendering and revision-confirmed profile plan/apply/rollback, plus
  macOS node_exporter and Technitium DNS monitoring in the Host and DNS dashboard.
- Offline checksum-pinned Operator scope tooling, an opt-in Infisical-to-Helm
  probe, scoped image recovery scripts, and interactive Grafana password
  recovery helpers. These tools require their own explicit execution scope.

## Changed

- Use source-traceable `git-<12-hex-source-commit>` build tags and digest-pinned
  deployment. Opt-in build reuse requires eligible matching inputs and private
  store provenance; KIND reuse verifies each node's digest, platform and full
  content. Local immutable collisions fail; registry collision checks remain
  an operator gate, and mutable-tag refresh is retained.
- Persist the completed homelab Grafana v1beta1 Connection/Auth/StaticSecret
  handoff with the existing `platform-secrets/kubedesk-infisical-reader`, one
  writer and Orphan retention for `grafana-admin`. Portable development and
  explicit Universal Auth remain supported.
- The Operator now watches only `platform-secrets` and `observability`.
  Retired `development-tools` manager RBAC and policy entries are removed from
  source; the dedicated reader's limited grants remain separate from the empty
  manager TokenRequest account lists.
- Preserve approved namespace routing through scoped Helm renderers: agent
  workloads in `platform-tools`, k6 in `platform-tests`, and Traefik in
  `platform-networking`, while retaining the existing Helm release records.
- Route development dashboards into Platform, preserve supplied UIDs and
  omitted/default fields during reconciliation, and use native-sidecar initial
  synchronization followed by Grafana's 30-second file polling. Dashboard
  delivery no longer needs admin reload credentials. Native-sidecar support is
  required for this profile.
- Retain the homelab's anonymous Grafana Editor setting and three-day
  Loki/Prometheus/Alertmanager history; Tempo's existing 72h setting is preserved.
  Monitoring uses the scoped rule renderer, and Loki sidecar configuration uses
  the validated schema supported by its pinned chart.
- `tls.secretName` selects a custom certificate name throughout Certificates,
  TLSStore, application overlays and the summary. Omitted or empty values keep
  the older domain-derived convention; explicit names survive `--domain`.
- New Infisical PostgreSQL installations use the default StorageClass. Existing
  StatefulSets and PVCs need a separate data migration to change storage class.

## Fixed

- Publish through the Host's local `crane` registry route, stage the resolved
  digest and register it through CRI before `image.pullPolicy=Never` rollouts,
  and restore missing KIND content before image reuse.
- Update only a marked block in CoreDNS's existing Corefile, with dry runs,
  optimistic concurrency and refusal of unmanaged rewrites.
- Support explicit local kubeconfig contexts and multi-file `KUBECONFIG`, handle
  Ingress resource backends in snapshots, and bound capability authorization
  checks with rules-review and access-review fallback.
- Reject ambiguous Host private IPv4 selection. DNS installation pins `kubectl`
  and supports explicit zone, context, interface, TTL, timeout and poll interval.
- Omit JSON content type on bodyless Infisical auth requests, preserve enrollment
  timing when intervals reload, and keep browser recovery and cancellation
  within the verified authority boundary.
- Gate dashboard watcher startup on initial collection, preserve normalized
  dashboard fields on reapply, and render a matching Certificate for the
  fallback TLSStore namespace.

## Breaking changes and migration

- Replace `KUBEDECK_*`, `kubedeck.io/v1alpha1` and `X-KubeDeck-Confirm` with their
  KuchDesk equivalents. Update module paths, binaries, chart/release names and
  agent Secret references together. The macOS installer does not remove the
  old `dev.kubedeck.host-agent` job automatically.
- Replace legacy CoreDNS custom ConfigMap/override settings with
  `KUCHDESK_COREDNS_CONFIGMAP` and `KUCHDESK_COREDNS_COREFILE_KEY`; remove obsolete
  `dnsManagement.overrideKey` and `createConfigMap` values. Back up the Corefile
  and review a dry run before enabling writes.
- Existing installations without a completed approved TLS migration must retain
  their current `tls.secretName`, such as `local-dev-tls`, before using the updated
  checked-in profile. Choose a distinct name when preparing a replacement domain
  certificate. Live TLS name migration, key issuance/copying and old-resource
  retirement remain separate approved operations; see the
  [lab migration boundary](../../lab/README.md).
- The homelab native-auth profile contains an existing public identity
  reference. Another installation must supply its own approved identity and
  reader settings. Do not replay the completed alpha-to-beta handoff, create
  competing writers, or blindly roll back to retired namespaces; see the
  [migration completion](../../lab/migrations/retired-namespaces/README.md).
- The probe's historical `development-tools` setup is outside the current
  Operator scope. Any new probe deployment needs its namespace and access
  reviewed separately. Shared database/messaging proposals remain proposals.
- Image retirement requires exact ownership, unused-reference and recovery
  checks in each store. Keep rollback or unique local-only content until its
  recovery or separately approved discard is established.
