# v0.13.1

## Fixed

- Apply the active dynamic MCP project, environment and path policy to both
  synchronous and queued secret-name listing. Queued work is authorized again
  when it runs, so a policy change after enqueue can prevent the upstream read.
- Denied name-list requests return the sanitized `policy_denied` error without
  sending a request to Infisical.

## Configuration

- No configuration change is required. Existing project, environment and path
  restrictions now apply to both name-listing tools.

## Installation

- Use the Host tools archive for the target platform and verify its published
  `SHA256SUMS` before installation.
- Reconnect the `kuchdesk-doctor` MCP server after replacing its binary, then
  verify the live source commit and `sourceModified=false` in capabilities.
