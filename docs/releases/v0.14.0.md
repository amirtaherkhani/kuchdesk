# v0.14.0

KuchDesk now targets fresh local development on Colima, containerd and k3s,
with direct YAML service configuration and shared local service access. The
active Infisical ENV Manager integration has been removed.

## Added

- Publish selected local service ports through the shared Colima/k3s access
  workflow, with read-only endpoint status for Mac, container and Pod clients.
- Configure installed services directly through their canonical YAML files.

## Changed

- Use Colima, containerd and k3s for fresh local development and image builds.
- Use the supported direct-YAML KuchDesk MCP and Agent workflows.
- Expose Alloy publication settings through the canonical YAML catalog.

## Removed

- Remove active Infisical ENV Manager UI, API, Agent, CLI, chart and MCP
  integrations. Historical release notes remain historical records.

## Migration

- Fresh local setup follows the Colima profile and direct YAML instructions in
  [the project guide](../../lab/README.md).
- Local service credentials belong in Git-ignored, restrictive-permission
  YAML files. Existing data volumes are not migrated or reset by this release.

[Full changes since v0.13.1](https://github.com/amirtaherkhani/kuchdesk/compare/v0.13.1...v0.14.0).
