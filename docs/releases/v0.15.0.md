# v0.15.0

KuchDesk separates environment ownership from disposable source checkouts and
keeps Host launchers stable as the Colima API endpoint changes.

## Changed

- Validate stable profile, repository, VM and cluster identities for environment
  ownership instead of treating a source path as the owner.
- Keep forwarding recovery state in a private environment directory and preserve
  retry-budget continuity across checkout changes.
- Anchor Host service installation to the permanent checkout and resolve the
  selected Colima API endpoint at each scheduled run.
- Clarify canonical service YAML defaults and private credential overlays.

## Migration required for existing profiles

Legacy checkout-path markers are rejected with a migration-needed diagnostic.
The read-only migration planner preserves the original marker and state; it
provides no automatic enrollment or migration-apply command. Existing-profile
activation requires separate reviewed ownership migration approval. This release
does not migrate persistent data, change credentials, or reset the environment.

## Artifacts

The source archive and macOS arm64 Host tool archive are accompanied by build
provenance and SHA-256 checksums. The Kubernetes Agent uses a separate immutable
source-derived image identity; publishing these archives does not deploy it.
